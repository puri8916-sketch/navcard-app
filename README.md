# Navigation Card Merger

เครื่องมือรวมไฟล์ "Navigation Card" ของนำร่องสงขลา (NavigationCard PDFs +
ReportCardIsClosedDaily.xlsx + CSV ตัวเลข) เป็น PDF เดียว 2 การ์ด/หน้า
พร้อมตรวจสอบความครบถ้วนอัตโนมัติ

## วิธีติดตั้ง (ทำครั้งเดียว)

ต้องมี Python 3.9 ขึ้นไปในเครื่อง (ดาวน์โหลดได้ที่ python.org ถ้ายังไม่มี)

เปิด Command Prompt / Terminal ในโฟลเดอร์นี้ แล้วรัน:

```
pip install -r requirements.txt
```

## วิธีใช้งาน

ในโฟลเดอร์นี้ รัน:

```
streamlit run app.py
```

เบราว์เซอร์จะเปิดเว็บหน้า Navigation Card Merger โดยอัตโนมัติ (ปกติที่
http://localhost:8501) ใช้งานได้เลย:

1. อัปโหลดไฟล์ zip ของชุดการ์ด (เหมือนที่เคยส่งให้ Claude)
2. กด "ตรวจสอบความครบถ้วน" — ระบบจะแจ้งถ้าขาดไฟล์การ์ด/ไม่มีแถวใน
   report/ไม่มีค่า LOA
3. เพิ่ม Remark ให้การ์ดที่ต้องการ (พิมพ์ข้อความเต็มได้เลย ระบบตัด
   บรรทัดให้เอง เป็นสีแดง ฟอนต์ลายมือไทยอัตโนมัติ)
4. กด "สร้างไฟล์ PDF รวม" แล้วดาวน์โหลด

## เมนู 📒 บันทึกเรือ

แทนแท็บรายวันในชีต "เล่มบันทึกข้อมูล" — เลือกวันที่, เพิ่มเรือ (LOA/Agent
เติมเองจากทะเบียนเรือ), บันทึกขาเข้า/ย้ายท่า/ขาออก, สถานะ รอยืนยัน/ปิดการเงิน,
ส่งออก CSV รายวัน แก้รายการ Pilot / Berth / From ได้ในแท็บ ตั้งค่า

ข้อมูลเก็บในเบราว์เซอร์ หรือใน Google Sheet เมื่อเชื่อมต่อแล้ว (ดูหัวข้อถัดไป)
กด "ดาวน์โหลดไฟล์สำรอง" ในแท็บ ตั้งค่า ได้ตลอด

## เมนู 🗓 จัดตารางเรือ

แทนแท็บวันที่ (ปริ้น) ของไฟล์ SHIP'S SCHEDULE FOR SONGKHLA PILOT — กรอกเรือครั้งเดียว ระบบจัดหน้าปริ้นให้เหมือนเดิม
- พิมพ์ชื่อเรือ → เติม LOA / ท่า / เอเย่นต์เอง · เวลาพิมพ์ `0630` ได้ (ตัดรอบ 17:00: ตารางวันที่ D = D 17:00 ถึง D+1 16:59)
- NO. รันเอง (เวลาเดียวกัน ออกก่อนเข้า) · เข้า/ออกเวลาเดียวกันอยู่แถวเดียวกัน · เว้นแถวเมื่อห่าง ≥ 2 ชม.
- ผก. ใส่ทีหลังได้ (แถวที่ยังไม่มีขึ้นสีเหลือง) · ปุ่ม +ออก สร้างเที่ยวออกจากเรือที่เข้า
- ติ๊ก พ = แจ้งเพิ่มหลังจัดจ่าย → ขึ้นท้ายตารางวันถัดไป
- แท็บ หน้าปริ้น → ปริ้น A4 แนวนอน 1 หน้า

ข้อมูลอยู่ใน Google Sheet แยก (`ShipSchedule_DB`) ไม่ใช่ชีตของบันทึกเรือ — แก้ทะเบียนเรือ (Ships), ท่า (Berths), เอเย่นต์ (Agents),
เบอร์ผก. (Pilots), เวรรายเดือน (Duty), เบอร์ติดต่อคอลัมน์ PILOT ON DUTY (FixedContacts), ตัดรอบ/เว้นแถว (Settings) ในชีตได้ตรงๆ
**ยกเว้นแท็บ Movements** ให้แก้ผ่านแอป

### ติดตั้งครั้งเดียว
1. อัปโหลด `ShipSchedule_DB.xlsx` (ไฟล์ฐานข้อมูลตั้งต้น — ไม่เก็บใน GitHub เพราะมีเบอร์โทร) ขึ้น Google Drive › เปิดด้วย Google ชีต › ไฟล์ › บันทึกเป็น Google ชีต
2. ในชีตนั้น ส่วนขยาย › Apps Script › วางโค้ดจาก `apps_script/Schedule.gs`
3. ตั้งค่าโปรเจกต์ (ไอคอนเฟือง): Time zone = **Asia/Bangkok** · Script properties › เพิ่ม `TOKEN` = รหัสที่ตั้งเอง
4. Deploy › New deployment › Web app · Execute as: **Me** · Who has access: **Anyone** › คัดลอก URL (/exec)
5. เปิดแอป › 🗓 จัดตารางเรือ › วาง URL + รหัส › ทดสอบและเชื่อมต่อ (ทำครั้งเดียวต่อเครื่อง)
   หรือใส่ใน Streamlit **Settings › Secrets** ให้ทุกเครื่องเชื่อมเอง:
```
[schedule]
url = "https://script.google.com/macros/s/……/exec"
key = "รหัสเดียวกับ TOKEN"
```

## เมนู 📑 ปิดการ์ดประจำวัน (รายงานการปิดการ์ด + รวมการ์ด)

วาง zip ชุดการ์ดทีเดียว (หลายวันวางหลาย zip พร้อมกันได้) → ขั้นที่ 1 รายงานการปิดการ์ด → ขั้นที่ 2 รวมการ์ดเป็น PDF เดียว · เครื่องคิดเลข ×3.2808 อยู่ด้านขวา

### ขั้นที่ 1 · รายงานการปิดการ์ดนำร่อง

วางไฟล์ `ReportCardIsClosedDaily.xlsx` → ระบบทำแท็บรายวัน (ชื่อแท็บ d-m) ในไฟล์รายงานประจำเดือน (เช่น `ต.ค.69.xlsx`)
รูปแบบเดียวกับไฟล์ของสำนักงาน (หัวรายงาน, สรุป ลำ/เข้า/ออก/เลื่อน, ผสานเซลล์, ชื่อและลายเซ็นผู้เซ็นท้ายแท็บ)
- ไฟล์ที่ครอบคลุมหลายวัน (เสาร์-อาทิตย์/เว้นหลายวัน) เลือกได้ว่าการ์ดไหนเป็นของแท็บวันไหน (ระบบเดาให้ก่อน)
- ติ๊ก "ส่งการเงินแล้ว" = แท็บสีเขียว
- นับ ลำ: ชื่อเรือซ้ำในแท็บเดียวกันนับครั้งเดียว · EN = เข้า · SA = ออก · SH = เลื่อน
- ข้อมูลและรูปลายเซ็นเก็บใน Google Sheet ที่เชื่อมต่อ (ไม่ได้เก็บใน GitHub) ครั้งแรกให้ นำเข้าไฟล์เดือนเดิม (ข้อ 3) เพื่อดึงแท็บเก่า + ลายเซ็น
- `report_template.xlsx` = แม่แบบรูปแบบ (ไม่มีข้อมูล/ลายเซ็น)

## ใช้ข้อมูลเดียวกันทุกเครื่อง (เชื่อมต่อ Google Sheet)

เมนู 📒 บันทึกประจำวัน และ 🧮 เครื่องคิดเลข (ความยาวเรือ ซึ่งเมนู ⚓ รวมการ์ดใช้ด้วย)
เก็บข้อมูลไว้ใน Google Sheet ของคุณได้ ทุกเครื่องที่เชื่อมต่อจะเห็นข้อมูลชุดเดียวกัน
ถ้ายังไม่เชื่อมต่อ ทุกอย่างทำงานเหมือนเดิม (เก็บในเบราว์เซอร์เครื่องนั้น)

### ติดตั้งครั้งเดียว (ประมาณ 10 นาที)

1. สร้าง Google Sheet ใหม่ ตั้งชื่ออะไรก็ได้ เช่น `navcard-app-data`
2. ในชีตนั้น เมนู **ส่วนขยาย › Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ `apps_script/Code.gs` ในโฟลเดอร์นี้
4. แก้บรรทัด `const KEYS = ['เปลี่ยนเป็นรหัสของคุณ'];` เป็นรหัสที่ตั้งเอง เช่น `['songkhla-2569']` แล้วกดบันทึก (ไอคอนแผ่นดิสก์)
5. กด **Deploy › New deployment** › ไอคอนเฟือง › เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วกด **Authorize access** เลือกบัญชี Google ของคุณ
     (ถ้าขึ้น "Google hasn't verified this app" กด Advanced › Go to … (unsafe) ได้ เพราะเป็นสคริปต์ของคุณเอง)
6. คัดลอก **Web app URL** (ลงท้าย `/exec`)
7. เปิดแอป › 📒 บันทึกเรือ › **ตั้งค่า › เชื่อมต่อ Google Sheet**
   วาง URL + รหัส แล้วกด **ทดสอบและเชื่อมต่อ**
   ข้อมูลเดิมในเครื่องนั้น (บันทึกประจำวัน + ความยาวเรือ) จะถูกส่งขึ้นชีตให้อัตโนมัติ
8. ทำข้อ 7 ในทุกเครื่อง/เบราว์เซอร์ที่ใช้ (ครั้งเดียวต่อเครื่อง)

ถ้ารันบน Streamlit Cloud จะใส่ใน **Settings › Secrets** แทนข้อ 7 ก็ได้ ทุกเครื่องจะเชื่อมต่อเอง:

```
[sync]
url = "https://script.google.com/macros/s/……/exec"
key = "songkhla-2569"
```

### การใช้งาน
- ป้ายบนหัวหน้าบันทึกประจำวัน: **☁ ซิงก์แล้ว** / **⚠ ออฟไลน์ · รอส่ง n** / **เก็บในเครื่องนี้**
- เน็ตหลุดยังบันทึกได้ ข้อมูลจะส่งขึ้นชีตเองเมื่อกลับมาออนไลน์
- เครื่องอื่นจะเห็นการแก้ไขภายในประมาณ 15 วินาที
- ข้อมูลอยู่ในแท็บ `data` ของชีต (คอลัมน์ "สรุป" อ่านง่าย) **อย่าแก้ข้อมูลในชีตโดยตรง** ให้แก้ผ่านแอป

### หลาย PORT (หลาย Google Sheet)
- แต่ละ PORT ใช้ Google Sheet + สคริปต์แยกกัน (ทำตามขั้นตอนติดตั้งซ้ำ ได้ URL คนละอัน)
- **ยกเลิกการเชื่อมต่อ** = ล้างข้อมูลในเครื่องนั้นทั้งหมด (ข้อมูลยังอยู่ครบในชีต) เชื่อมใหม่เมื่อไหร่ก็โหลดกลับมา
- เปลี่ยนไปเชื่อมชีตอื่น = ล้างข้อมูลชีตเดิมออกจากเครื่อง แล้วโหลดจากชีตใหม่ ข้อมูลไม่ปนกัน
- ถ้ายังมีข้อมูลรอส่ง (ออฟไลน์) จะยกเลิก/เปลี่ยนชีตไม่ได้ จนกว่าจะส่งขึ้นชีตเดิมสำเร็จ
- เครื่องที่กดยกเลิกจะไม่เชื่อมเองจาก Secrets อีก ต้องกรอก URL + รหัสใหม่ที่ ตั้งค่า

### เพิ่มผู้ใช้ / ใส่รหัสคนอื่นในอนาคต
1. เพิ่มรหัสใน `KEYS` เช่น `['songkhla-2569', 'รหัสของคนที่สอง']`
2. **Deploy › Manage deployments** › ไอคอนดินสอ › Version: **New version** › Deploy (URL เดิมไม่เปลี่ยน)
3. ให้คนนั้นใส่ URL + รหัสของเขาในหน้า ตั้งค่า

ยกเลิกสิทธิ์: ลบรหัสนั้นออกจาก `KEYS` แล้ว deploy version ใหม่ตามข้อ 2

## ไฟล์ในโฟลเดอร์นี้

- `pilot_log.html` — หน้าบันทึกเรือ
- `schedule.html` — หน้าจัดตารางเรือ (เมนู 🗓)
- `apps_script/Schedule.gs` — สคริปต์ฝั่ง Google Sheet ของตารางเรือ (ชีตแยก)
- `sync_client.js` — ตัวซิงก์ข้อมูลกับ Google Sheet (ใช้ร่วมกันทุกเมนู)
- `apps_script/Code.gs` — สคริปต์ฝั่ง Google Sheet (วางใน Apps Script ตามขั้นตอนด้านบน)
- `ship_database.csv` — ทะเบียนเรือตั้งต้น (ชื่อเรือ, LOA ฟุต, Agent) ใช้ครั้งแรกที่เปิด

- `app.py` — หน้าเว็บ (Streamlit UI)
- `nav_core.py` — ตรรกะหลักทั้งหมด (อ่านไฟล์, จับคู่ชื่อเรือกับ LOA,
  วาดข้อมูลลงการ์ด, รวมหน้า)
- `caveat_fixed.ttf` — ฟอนต์ลายมือสำหรับตัวเลข/ข้อมูลในตาราง
- `requirements.txt` — รายชื่อไลบรารีที่ต้องติดตั้ง

## กฎที่ฝังไว้ในโปรแกรมแล้ว

- จับคู่ค่า LOA (CSV) กับเรือ **ตามชื่อเรือ** ไม่ใช่ตามลำดับแถว
- Pilot = 000 แสดงเป็น **-CAP-** สีแดงเสมอ
- Remark ที่เพิ่ม: สีแดง, ฟอนต์ลายมือไทย, บรรทัดแรกชิดซ้าย
- รองรับเลขการ์ดทั้งแบบเก่า (SGZxxxx/69) และแบบปีงบประมาณใหม่ (SGZn/70)

## ข้อจำกัดเทียบกับตอนทำผ่านแชท

- การแก้ไขข้อมูลเฉพาะจุด (เช่น เปลี่ยน draft/berth ของแถวใดแถวหนึ่ง,
  บีบจำนวนแถวสำหรับเรือที่มี leg เกิน 7) ยังไม่มีช่องกรอกในหน้าเว็บ —
  ต้องแก้ใน `nav_core.py` ชั่วคราว หรือแจ้งมาให้ช่วยเพิ่มช่องกรอกทีหลัง
- รวม 2 วันเป็นไฟล์เดียว (เช่นกรณีการ์ดวันที่ 23-24) ยังต้องทำด้วยมือ
  (รวม zip 2 ชุดเป็นโฟลเดอร์เดียวก่อนอัปโหลด)
